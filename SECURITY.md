# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest userscript on `main` | Yes |
| Older installed versions | No |

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

Use the repository's private security-advisory flow instead: [report a vulnerability](https://github.com/SharpSplinter/Naughty-Inventory-Companion/security/advisories/new). Include a clear description, affected script version, reproduction steps, likely impact, and a safe proof of concept when possible.

Do not include Torn API keys, account data, complete backups, or unredacted inventory exports. A maintainer will aim to acknowledge a valid report within seven days and will coordinate a fix and disclosure timeline with the reporter.

## Scope

This policy covers this repository's userscript, local backup/export handling, local storage adapter, and TornPDA bridge use. It does not cover Torn, Tampermonkey, TornPDA, GitHub, or third-party services themselves, though reports about unsafe integration behavior are welcome.

There is no bug-bounty program. Good-faith research that avoids privacy harm, service disruption, and access to other users' data is appreciated.
